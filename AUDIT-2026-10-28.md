## High-priority defects and risks

1. **Historical strategy limitations:** `historical_breakouts` returns only the most recent 50 detailed trades. `compare_strategies` evaluates these rather than the full historical record; its reported “base” summary is not the full underlying backtest.
2. **Synthetic smoke tests only:** `integration/tests/test_imported_theta.py` checks seven basic paths, not actual gateway/HLP/CCXT integration, historical orderflow replay, broker fills, or the WebAssembly build.
3. **Unverified candle completeness and venue coverage:** the API filters by Hyperliquid `T < now`; no exchange clock synchronization, staleness threshold, or cross-venue reconciliation.
4. **Risk model omits fees, funding, slippage and gap/liquidation risk.** Treat position suggestions as mathematical examples.
5. **CORS / local access:** Python HTTP server binds to `127.0.0.1` and advertises a fixed browser origin. Good default for localhost; it does not replace authentication if exposed externally.
6. **Continuous integration coverage:** the root Python workflow triggers only on `integration/**` and its own YAML, so a vendor-only import does not run it. No observed passing CI status on import commit.
7. **Documentation:** root README was stale after import. Update it to distinguish imported upstream code from integrated product functionality.
8. **Public repository:** license and sensitive-data review remain important. Search-based checks alone are insufficient to certify absence of secrets. Audit git history, generated assets, and dependencies.
